## 1. Software Engineer / Full-Stack Developer Roles

- **MicroSetu — Alternative Credit Underwriting & POS Platform for Informal Merchants**
  - Architected an end-to-end FinTech platform with **FastAPI**, **Python**, and modern **JavaScript (ES6+)** to underwrite micro-loans for unbanked street vendors using high-frequency UPI cash-flow footprints.
  - Implemented an asynchronous RESTful backend serving automated credit scoring, fraud detection heuristics, and probabilistic cash-flow forecasting with sub-20ms response times.
  - Built a **Voice-First Smart Ledger** integrating the browser's native **Web Speech API** with regex-based semantic parsing, converting spoken Hindi/Hinglish receipts into structured double-entry accounting records for semi-literate merchants.
  - Engineered an **Anti-Fraud Shield** validating 12-digit NPCI routing checksums and maintaining an in-memory sliding window cache to detect and block duplicate payment screenshot replay attacks.
  - Designed an interactive, modular UI with dynamic HTML5 Canvas BharatQR generation, real-time multilingual audio soundbox synthesis, and responsive Chart.js time-series analytics.

## 2. Machine Learning / FinTech Data Science Roles

- **MicroSetu — Cash-Flow Credit Risk & Underwriting Engine**
  - Developed an alternative credit risk engine using **Scikit-Learn (Gradient Boosting)** evaluating 13 behavioral cash-flow features (turnover stability, ticket variance, repeat customer loyalty) to assess creditworthiness without traditional bureau scores.
  - Built an interpretable feature attribution module translating model risk weights into human-readable positive/negative credit drivers for institutional lenders under RBI fair practice guidelines.
  - Implemented a time-series cash-flow forecaster with 30-day projection horizons and day-of-week seasonality, calculating safe daily micro-deduction debt caps (10–12% of revenue) to prevent vendor default.
  - Calibrated synthetic merchant cohorts across 6 retail categories using empirical distributions from RBI Payment System statistics and published informal sector field surveys.
